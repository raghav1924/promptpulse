# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

If you discover a security issue or input validation vulnerability in PromptPulse, please report it via email to **[raghavjatin245@gmail.com](mailto:raghavjatin245@gmail.com)**.

Please include:
1. Vulnerability description and steps to reproduce.
2. Sample suite or test inputs.
3. Impact assessment.
