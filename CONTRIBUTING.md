# Contributing to PromptPulse

Thank you for contributing to **PromptPulse**! We welcome community contributions to improve prompt regression testing and assertion tooling.

## Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/raghav1924/promptpulse.git
   cd promptpulse
   ```

2. **Compile TypeScript:**
   ```bash
   npm run build
   ```

3. **Run Unit Tests:**
   ```bash
   npm test
   ```

## Pull Request Guidelines

- Ensure all unit tests pass with `npm test`.
- Maintain zero external dependencies using Node.js standard libraries.
- Write conventional commit messages (`feat:`, `fix:`, `docs:`, `test:`).
- Document new assertion types in `README.md`.
