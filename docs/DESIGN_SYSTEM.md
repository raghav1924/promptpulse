# PromptPulse Design System

Embodying the **29 Master Design Patterns**:

- **Bento Grid (#12)**: Asymmetric layout organizing prompt regression metrics, score diffs, and test assertions.
- **Dark Mode UI (#20)**: High-contrast obsidian canvas optimizing side-by-side prompt diffing.
